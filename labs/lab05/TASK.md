# ЛР5. Переданный форматтер

Вариант: **Audit**.

## Что дано

Сервис игнорирует аргумент `formatter`. Два вызова `build_service()` случайно используют одно хранилище. Основной метод `AuditService.render()` также нужно реализовать; готовые проверки объектов и зависимостей не переписывайте.

## Задание

### Шаг 1. Сохраните зависимости и настройте сборку

В `AuditService(repository, formatter)` используйте переданный объект. `build_service()` должен создавать отдельное хранилище для каждого вызова.

Реализацию хранения не переписывайте. Явно переданное двум сервисам одно хранилище должно оставаться общим.

### Шаг 2. Реализуйте `AuditService.render()`

Сначала выберите события через `find()`. Для каждого вызовите форматтер ровно один раз, проверьте строку готовой `format_result()` и верните `tuple`. Чтение и ошибка форматтера не удаляют события.

### Шаг 3. Проверьте отказ и следующий вызов

Контрольный исполнитель сначала выбрасывает `DomainError("TEMPORARY")`, затем успешно работает. Первый вызов не повторяется автоматически и не меняет данные; второй использует того же исполнителя. `TEMPORARY` — код учебной проверки, не новая ветка бизнес-логики. Отсутствие зависимости проверяйте через `is None`, а не её истинность.

### Шаг 4. Обязательная практическая часть

В `AuditService` реализуйте `event_counts(entity_id=None)` — количество событий каждого типа через `find()`. `latest_event(entity_id=None)` возвращает самое позднее событие по `(timestamp, event_id)` или `None`. Форматтер и хранилище не изменяйте.

## Примеры и границы

- Контрольный форматтер возвращает `CUSTOM:E1`; эта строка появляется в `render()`.
- Разные форматтеры дают разные представления.
- Ошибка форматирования не удаляет ранее записанное событие.
- Раздельные хранилища независимы; результат нестрокового типа вызывает `INVALID_FORMAT_RESULT`.

Последовательности и конфигурации дополнительно проверяются в `tests/test_progression.py`. Прочитайте ожидаемый результат каждого сценария до реализации.

Все проверки открыты: `tests/test_contract.py` и `tests/test_review_contract.py`.
